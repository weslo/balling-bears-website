# 🐻 Balling Bears Website

Website for the Balling Bears World of Warcraft raiding guild on Mal'Ganis.

This is a small React and TypeScript site built with Vite. It is meant to be quick to run locally and easy to update.

## 🛠️ Local Development

Install dependencies:

```bash
npm install
```

Start the local site:

```bash
npm run dev
```

Edit files in `src/`. The browser will reload as you make changes.

Run the current project check:

```bash
npm run build
```

There is no separate test command yet. Treat a failed build as something to fix before opening a pull request.

## 🤝 Contributing

Create a new branch for your change and open a pull request into `main`.

`main` is protected. Changes need an approved pull request before they are merged. Public visitors can open and review pull requests, but only approved project collaborators can approve changes for merge.

Keep pull requests focused, explain what changed, and include how you checked the work.
